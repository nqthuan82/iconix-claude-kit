## Gate-specific checks

### M1 only
- [ ] Every UC cites ≥1 REQ in `## Traceability`; every REQ is cited by ≥1 UC
- [ ] Every UC has basic course + ≥1 alternate course, active voice
- [ ] No UC exceeds one page when rendered
- [ ] Initial domain model exists; all PO `' VERIFY:` notes either resolved or queued for M2
- [ ] Every "system invokes UC-XXX" reference matches Traceability `Invokes:` (PO rule 12); Traceability check #14
- [ ] Every UC belongs to one package overview; no orphan / ghost UCs

### M2 only
- [ ] Every UC has a robustness diagram; zero RB rule violations
- [ ] Every UC has `container-mapping/UC-XXX-containers.md` with ≥1 container, ≥1 testability seam noted
- [ ] Every UC has `nfr-annotations/UC-XXX-nfr.md` consistent with the catalog
- [ ] `docs/architecture/package-map.md` exists; every UC in allocation table
- [ ] `docs/architecture/integration-surface.md` exists; every external call documented
- [ ] Every catalog NFR cited by ≥1 ADR or container-mapping (Traceability check #9)
- [ ] All PO `' VERIFY:` notes resolved (Analyst PDR readiness)
- [ ] Concurrent-touch report (`change-impact/CT-<date>.md`) reviewed; HIGH conflicts resolved or `[CT-ACCEPT-XXX]` accepted
- [ ] No blocking architectural questions open without `[Proposed ADR-XXX]`

### M3 only
- [ ] Every UC has a sequence diagram (`sequence/SD-XXX-<slug>.puml`)
- [ ] Every controller on the matching RB has corresponding messages on the SD
- [ ] Class model has attributes + operations; no attribute-sparse entities
- [ ] Every controller has ≥1 test case; test plan complete
- [ ] No code under `src/` in M3 PR (Implementation is separate)
